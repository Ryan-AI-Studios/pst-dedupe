## Blind-Spot Headlines

1. **False-Pass Hazard on Non-Privilege Code Application:** If `review_codes_preview` has a defect where it flags *any* tag application as requiring a privilege confirmation, testing only the `privilege` tag will pass trivially. Tests must assert that adding `responsive` or `confidential` returns `privilege_would_change == 0` without triggering the modal.
2. **Missing FTS Index Error Specificity:** A generic error check (`assert!(res.is_err())`) will pass on any unexpected failure. Tests must assert `err.kind == "fts_unavailable"` and verify the remediation instruction.
3. **Disjoint Offset Pagination Invariance:** Tests for pagination must assert strict disjoint set intersection (`set_a ∩ set_b == ∅`) between consecutive pages to prove SQL sorting tiebreakers are deterministic.
4. **Tauri IPC Capability Registration:** Adding 6 new commands (`review_queue_page`, `review_code_catalog`, `saved_searches_list`, `saved_search_upsert`, `review_codes_preview`, `review_apply_codes`) requires adding corresponding permission definitions under `crates/dedupe-chrome/capabilities/default.json` and permissions config, otherwise IPC invokes will be rejected at runtime.
